# ブランチ作業手順

ユーザーがGitの作業ブランチの作成、チェックアウト、名前変更、切り替えを依頼したときに使用する。

## 手順

1. 変更前に現在のブランチ、作業ツリー、ローカルブランチ、関連するリモートを確認する。
2. 既存の変更と未追跡ファイルをすべて保持する。切り替えを容易にするために`git reset --hard`や`git checkout --`などの破壊的なコマンドを使わない。
3. 指定されたブランチがローカルにあればチェックアウトする。リモートにのみ存在する場合は、追跡設定付きのローカルブランチを作成する。
4. ブランチが存在しない場合、ユーザーの意図が明確なときだけ名前を推測する。不明確なら確認する。作業内容に応じて`feature/`、`fix/`、`chore/`、`docs/`の接頭辞を優先する。
5. 意図したベースから`git switch -c <branch>`で新しいブランチを作成し、最後にブランチ名と状態を確認する。

未コミットの変更が切り替えと競合する場合、ベースブランチが不明確な場合、または明示的に許可されていないstash・commitが必要な場合は停止してユーザーに確認する。

最終的なブランチ、ベースの判断、保持した既存変更を報告する。
